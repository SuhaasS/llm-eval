# LLM Judge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the second grading channel from `docs/superpowers/specs/2026-08-18-judge-design.md` — a neutral-family LLM judge that ranks submissions the deterministic ladder has already gated.

**Architecture:** Four new units beside the existing grading path: `similarity.py` (three deterministic context facts, explicitly not a score), `judge_schema.py` (`JudgeRecord` + append-only jsonl + gzipped payloads), `judge.py` (whitelist payload builders, prompt render/parse, vote protocol, live completion), `scripts/judge.py` (resumable batch driver + summary printout). Judgments are a derived view: `<event-log>/judgments/` sits beside `grades/`, never inside it, and nothing ever writes the event log or `grades.jsonl`.

**Tech Stack:** Python ≥3.11, frozen dataclasses (no pydantic), litellm==1.95.0 (pinned, in-process Router), pytest.

## Global Constraints

- Package `bakeoff/src/bakeoff/`, src layout; `scripts/` importable as `scripts.judge` (`pythonpath=["."]`); scripts carry the `REPO`/`sys.path` bootstrap header exactly as `bakeoff/scripts/grade.py:75-77` does.
- Frozen dataclasses + hand-rolled `to_dict`/`from_dict`; a `_build()` helper copied (not imported) from `grade_schema.py` that drops unknown keys. No pydantic anywhere.
- Docstrings carry the *why* and the failure mode, cross-referenced to spec sections (house style — see `grade_schema.py` module docstring). Test names are full sentences.
- Append-only jsonl: open mode `"a"`, `flush()` + `os.fsync()` per line, no update/delete API. A re-judge is a new line.
- **Nothing ever writes the event log or `grades.jsonl`.** The driver opens them read-only.
- Reference anchor is **`TaskManifest.solution_diff`** (`tasks.py:194`), never `TaskManifest.reference_diff` (that includes the test half the agent was handed at start). Candidate diff is **`RunRecord.artifacts.final_diff`** — diff TEXT; every other `artifacts.*` field is an absolute path embedding `<task_id>-<model>-<sample_index>`.
- The judge payload is built by **whitelist, never redaction**: a `RunRecord` field added tomorrow must be absent from the payload by default.
- No code path may write a rubric `JudgeRecord` for a run whose `resolved` is not `True`. `resolved is None` runs are never judged at all.
- Offline test gate: `addopts = "-m 'not integration'"`. Run the suite as `cd bakeoff && .venv/bin/python -m pytest tests/ -v`. The one paid test carries `integration` **and** `judge_live` markers, and `verify_logger.py`'s selector must exclude `judge_live`.
- `human_grader_record` (§6.3 second half) is **out of scope** — a docstring note in `judge_schema.py` points at §6.3; no stub class.
- Judge model id pinned: `openai.gpt-5.6-sol` default, CLI-overridable, never an alias.
- Commit after each task with a conventional message (`feat: …` / `test: …`).

## Resolved spec ambiguities (binding for all tasks)

1. **Canonical pair identity**: `run_id_a`/`run_id_b` stored lexicographically sorted; `position_assignment ∈ {"a_first","b_first"}` records shown order; `verdict ∈ {"a","b","tie","gate_decided"}` refers to **canonical** a/b. The stored payload holds diffs in **shown** order.
2. **`gate_decided`**: one line per pair — `gate_decided_by ∈ {"a","b"}` = the side that passed the gate, `vote_index=None`, `position_assignment=None`, no payload, no model call.
3. **Gating view**: last line in file order per `run_id` in `grades.jsonl`. `grade_version_seen` is `dict[run_id -> grader_version]` (one entry for rubric, two for pairwise; the spec's scalar cannot describe a mixed-version pair).
4. **Rubric is one call** (`vote_index=0`); three votes are pairwise-only. Matches spec cost math (4 rubric calls per task-sample).
5. **`sample_index` is not on `GradeRecord`** — the driver joins `EventLog.read_run(run_id)` for `sample_index`, `model`, `attempt_number`, `artifacts.final_diff`. Within a `(task_id, sample_index, model)` cell, keep the max-`attempt_number` run that has a grade line.
6. **Checks enter the payload as `{"name","status"}` only** — `output_path` embeds the arm name in a directory component, `detail` is free text, and durations are the timing leak class.
7. **Malformed verdict**: re-send the *same rendered prompt* as up to 2 more fresh independent calls (never a repair turn — feeding the model its own bad output is a prior-verdict leak); exhausted → raise, driver counts an error, writes no line, exits 1.
8. **Any malformed line in `grades.jsonl` refuses judging outright** (no flag cures it — an unreadable gate might be the gate). `--re-judge` only cures malformed `judgments.jsonl`.
9. **`judgment_id` = `uuid.uuid4().hex`**. `input_payload_sha` = sha256 of the **uncompressed** canonical JSON (`json.dumps(payload, sort_keys=True)` bytes). Gzip written with `mtime=0` (a naive write embeds a timestamp and makes identical payloads hash-unstable on disk), atomically via tmp + `os.replace`. `scan_secrets` (`scanners.py:116`) runs on the canonical JSON **before** any bytes hit disk (§6.5); a hit raises `PayloadSecretsFound` and leaves no file.
10. **Per-task seeded rubric items (§3.3)**: `TaskManifest` carries no rubric field today; deferred until it does. The whitelist means the key is simply absent.

## Verification (whole plan)

### Task 1: `similarity.py` — deterministic context, explicitly not a score

**Files:**
- Create: `bakeoff/src/bakeoff/similarity.py`
- Test: `bakeoff/tests/test_similarity.py`

**Interfaces:**
- Consumes: `bakeoff.tasks.diff_chunks(diff: str) -> list[str]` (`tasks.py:229` — reuse it; it already handles the `\x0c`-in-splitlines trap that broke five drafts of the diff splitter).
- Produces (Task 3 imports these exact names):

```python
@dataclass(frozen=True)
class OverlapSet:
    common: tuple[str, ...]
    candidate_only: tuple[str, ...]
    reference_only: tuple[str, ...]

@dataclass(frozen=True)
class SimilarityContext:
    # Three independent facts. NO score field, NO __lt__, NO aggregate —
    # §4.2.1: similarity informs judgment and never contributes to a score.
    file_overlap: OverlapSet
    symbol_overlap: OverlapSet
    diff_size_ratio: float | None   # None when the reference changes 0 lines
    def to_dict(self) -> dict[str, Any]: ...

def diff_files(diff: str) -> tuple[str, ...]        # sorted, deduped
def diff_symbols(diff: str) -> tuple[str, ...]      # hunk-header context after the second @@; sorted, deduped
def changed_line_count(diff: str) -> int            # +/- lines, excluding +++/--- file headers
def similarity_context(candidate_diff: str, reference_diff: str,
                       drop_paths: Iterable[str] = ()) -> SimilarityContext
```

**Design points:**
- Pure functions, no subprocess, no git, no filesystem. Extract paths lexically from `+++ b/…` lines per chunk (`/dev/null` on the `+++` side means use the `--- a/…` path — a deletion still touched that file). Document the limitation: pathological quoted filenames degrade a *context signal*, not a score.
- `drop_paths` (the caller feeds `TaskManifest.extra_files`) drops whole chunks from **both** diffs before computing all three facts — `tasks.py:214`'s comment ("so the offline grader can drop them from any diff-similarity metric") was written for this parameter.
- `diff_size_ratio = candidate_changed_lines / reference_changed_lines`; guard division by zero as `None`, never `inf` or a fabricated `0.0`.

Payload shapes (closed key sets — tests assert exact equality at every nesting level):

```python
# rubric
{"kind": "rubric", "task_prompt": str, "reference_diff": str, "candidate_diff": str,
```

### Task 4: prompts, parsing, votes (`judge.py`, second half)

**Files:**
- Modify: `bakeoff/src/bakeoff/judge.py`
- Test: `bakeoff/tests/test_judge.py` (extend)

**Interfaces:**
- Consumes: Task 3's `PayloadInputs`, `build_rubric_payload`, `build_pairwise_payload`.
- Produces (Tasks 5/6 rely on these):

```python
JUDGE_MODEL_ID_DEFAULT = "openai.gpt-5.6-sol"
JUDGE_PROMPT_VERSION = 1
RUBRIC_VERSION = "1.0.0"
JUDGE_SAMPLING: dict[str, Any] = {"temperature": 0.0, "max_completion_tokens": 4096}
RUBRIC_DIMENSIONS = ("functional_equivalence", "completeness", "cross_file_consistency",
                     "scope_discipline", "convention_adherence")
RUBRIC_FLAGS = ("introduced_stub", "left_debug_artifacts", "wrote_tests")

CompleteFn = Callable[[str], str]   # rendered prompt -> raw model text. THE seam.

class MalformedVerdict(RuntimeError): ...

@dataclass(frozen=True)
class RubricResult:
    dimension_scores: dict[str, int]
    flags: dict[str, bool]
    reasoning: str

@dataclass(frozen=True)
class VoteOutcome:
    position_assignment: str   # "a_first" | "b_first"
    verdict: str               # "a" | "b" | "tie" — canonical, already mapped back
    payload: dict[str, Any]    # SHOWN order, as sent
    rendered_prompt: str
    reasoning: str

def render_rubric_prompt(payload: dict) -> str
def render_pairwise_prompt(payload: dict) -> str
def prompt_sha(rendered: str) -> str
def parse_rubric_response(text: str) -> RubricResult
def parse_pairwise_response(text: str) -> str        # "first"|"second"|"tie"
def judge_rubric(inputs: PayloadInputs, complete: CompleteFn,
                 retries: int = 2) -> tuple[dict, str, RubricResult]
def judge_pair_vote(a: PayloadInputs, b: PayloadInputs, rng: random.Random,
                    complete: CompleteFn, retries: int = 2) -> VoteOutcome
def majority(verdicts: Sequence[str]) -> str         # "a"|"b"|"tie"; no strict majority -> "tie"
```

**Design points:**
- `judge_pair_vote` order of operations: (1) draw `a_first = rng.random() < 0.5` **before** building the payload; (2) `build_pairwise_payload(first, second)` in shown order; (3) render — the template interpolates payload sections verbatim (task prompt, reference diff, "Submission A"/"Submission B" blocks each with diff + checks + similarity) and demands one JSON object `{"verdict": "A"|"B"|"TIE", "reasoning": "..."}`; (4) `prompt_sha` over the exact rendered text (per call — position changes the text); (5) `complete(rendered)`, parse, on `MalformedVerdict` re-call the same rendered prompt up to `retries` more times as fresh independent calls; (6) map `"first"/"second"` back through the position draw to canonical `"a"/"b"`.
- Rubric prompt: anchors each of the five dimensions with its 0/1/2 meaning from the spec (0 fails / 1 partial / 2 meets); demands one JSON object `{"dimension_scores": {...}, "flags": {...}, "reasoning": "..."}`. Functional equivalence is anchored as "accomplishes what the reference accomplished — explicitly NOT 'is the same code'".
- Parsing: strip code fences, extract the first balanced `{...}`, `json.loads`, then strict domain validation. Rubric: exactly `RUBRIC_DIMENSIONS` keys, int values in `{0,1,2}` with **booleans explicitly rejected** (`isinstance(True, int)` is Python's trap — check `type(v) is int`), exactly `RUBRIC_FLAGS` keys with real bools, non-empty `reasoning` string. Pairwise: verdict case-insensitive in `{"A","B","TIE"}`. Unknown top-level keys tolerated (models editorialize); unknown or missing dimension names are `MalformedVerdict`.
- Three votes = three `complete` calls with independently drawn positions and no shared context. The stateless `str -> str` seam makes shared context structurally impossible — that is why the seam sits at raw-completion level, not around `judge_one`.

**Files:**
- Create: `bakeoff/scripts/judge.py`
- Test: `bakeoff/tests/test_judge_script.py`

**Interfaces:**
- Consumes: everything from Tasks 1–5; `EventLog` (`eventlog.py:20` — `read_run`, `list_runs`); `load_grades` (`grade_schema.py:382`); `load_task_set` (`tasks.py:721`); `task_set_commit` via manifest.
- Produces:

```python
class ResumeRefused(RuntimeError): ...       # own copy, grade.py precedent
class GateInvariantError(RuntimeError): ...  # a rubric JudgeRecord about a non-resolved run is a DRIVER bug

def judgments_path(event_log_root) -> Path   # <root>/judgments/judgments.jsonl
def payloads_root(event_log_root) -> Path    # <root>/judgments/payloads
def gating_view(grades: list[GradeRecord]) -> dict[str, GradeRecord]  # last line per run_id, file order

def judge_event_log(event_log_root, tasks, *,
                    complete: CompleteFn | None = None,   # seam 1; None -> live_completion(judge_model_id), lazily
                    rng: random.Random | None = None,     # seam 2
                    judge_model_id: str = JUDGE_MODEL_ID_DEFAULT,
                    only_tasks: Iterable[str] | None = None,
                    sample_indices: Iterable[int] | None = None,  # subsample SAMPLES, never pairs
                    votes: int = 3, rubric: bool = True,
                    re_judge: bool = False) -> dict
# returns {"judged", "gate_decided", "skipped", "errors", "warnings", "summary",
#          "audited", "from_prior_invocations"}

def main(argv: list[str] | None = None) -> int
# --event-log (required), --taskset (default REPO/"taskset"), --only-task, --samples,
# --re-judge, --judge-model, --votes, --no-rubric
# exit 0 = every selected unit produced its lines; 1 = any error or refused resume
```

**Driver algorithm (the order is the content):**
1. `load_judgments` → malformed and not `re_judge` → `ResumeRefused` (an unreadable judgment is not an absent judgment).
2. `load_grades` → **any** malformed → refuse outright, no flag cures it (ambiguity resolution 8).
3. `gating_view` = last line per `run_id`; build `done` key sets from existing judgments: rubric `("rubric", run_id, judge_model_id, judge_prompt_version, rubric_version)`; pairwise `("pairwise", task_id, sample_index, run_id_a, run_id_b, vote_index, judge_model_id, judge_prompt_version, rubric_version)` — gate-decided lines carry `vote_index=None` and resume as their own unit.
4. For each graded `run_id`: `EventLog.read_run` for `sample_index`, `model`, `attempt_number`, `artifacts.final_diff`. Runs in the log with no grade line → warning, never judged (rescuing an ungraded run is out of scope). Drop `resolved is None` **before** grouping (an excluded run is not an observation of the model). `sorted()` everywhere — glob order is nondeterministic and resume needs determinism.
5. Group by `(task_id, sample_index)`; within a cell keep max-`attempt_number` graded run per model; apply `only_tasks`/`sample_indices` filters.
6. **Rubric** (if enabled): only for `resolved is True` runs; assert `resolved is True` immediately before `append_judgment` — violation raises `GateInvariantError` (§4.2.3's central rule, the `_assert_verdict_invariant` precedent).
7. **Pairwise**: model pairs in sorted order; canonical a/b by sorted `run_id`. Both resolved → `votes` independent `judge_pair_vote` calls, one line each, `write_payload` **before** `append_judgment` (a line pointing at a payload that failed to write is the bad order). Exactly one resolved → one `gate_decided` line (`gate_decided_by` = passing side, no call, no payload). Neither → nothing.
8. Per-unit `try/except Exception` → `errors`, continue; append inside the try after the invariant assert. Exit 1 iff `errors`.
9. The driver never opens the event log or `grades.jsonl` for writing.
10. `judged_at` = `datetime.now(timezone.utc).isoformat()` per record; `grade_version_seen` from the gating lines used; `graded_against_task_set_commit` from the manifest.
